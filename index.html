Sobre mí

Trabajo en la intersección entre el negocio y el código. Empecé en Reba Compañía Financiera atendiendo clientes y entendiendo cómo funcionaban de verdad los productos —FCI, tarjetas, transferencias, dólares—. Ese conocimiento me llevó al área de Ingeniería, primero como analista funcional resolviendo incidentes productivos con logs, trazas y SQL, y después como desarrollador backend en Java y Spring Boot.

Mi foco hoy son los microservicios y las APIs para productos financieros. Integré 3D Secure (Prisma) en la autenticación de transacciones e-commerce, desarrollé el flujo completo de naturalización de clientes extranjeros y trabajé en funcionalidades para Onboarding, Fraude, Prevención de Lavado de Dinero y Operaciones.

Además de Java, trabajo con .NET: en ProTraining desarrollé el backend de una plataforma de 5 microservicios con PostgreSQL independiente por servicio, API Gateway, JWT y aislamiento multi-tenant verificado con tests. En SubastaYa construí pujas en tiempo real con SignalR y una billetera con retención de saldo tipo escrow.

Entre 2025 y 2026 me dediqué de lleno a la facultad: en 2026 promocioné 8 materias y estoy a una (Física II) de recibirme de Analista Programador en la UNAJ. Después siguen dos años más para Ingeniería Informática.

ProTraining

Destacado

Plataforma de gestión de entrenamiento · Proyecto académico UNAJ

Backend de 5 microservicios con base PostgreSQL independiente por servicio, detrás de un API Gateway (YARP), con JWT, logging estructurado (Serilog + correlation ID) y resiliencia en las llamadas HTTP (retry, timeout, circuit breaker). Aislamiento multi-tenant con filtro global a nivel de DbContext y tests que bloquean el merge si una entidad nueva rompe el aislamiento. Incluye un servidor MCP para exponer la biblioteca de ejercicios a clientes de IA y un asistente con LLM local (Ollama) con fallback a Gemini.
