## Cómo verlo localmente

Solo abrí `index.html` en el navegador (doble click), o usá una extensión como "Live Server" en VS Code.

## Despliegue en GitHub Pages

El sitio se publica desde la rama `main`, carpeta `/ (root)`.

```bash
git add .
git commit -m "feat: agregar sección de proyectos y actualizar contenido"
git push origin main
```

En un par de minutos GitHub Pages reconstruye el sitio automáticamente.
